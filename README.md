# Rainbow Blast

Blokjespuzzel met Katrien (Block Blast zonder advertenties) voor Wyne en Viggo, met een 3D-eiland om te bouwen. PWA, werkt volledig offline op de iPad.

```bash
npm install
npm run dev        # ontwikkelen
npm test           # spellogica
npm run build      # naar dist/
```

Live via GitHub Pages: elke push naar `main` bouwt en publiceert (`.github/workflows/deploy.yml`).
Op de iPad: open de link in Safari, deel-knop, "Zet op beginscherm". Daarna werkt het spel zonder internet.
